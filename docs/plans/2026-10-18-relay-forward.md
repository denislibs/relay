# Пересылка сообщений как в Telegram — план

Цель: пересылать сообщения (одно, альбом, выбранные несколько) в один или несколько чатов, как в Telegram Web A.
Код Telegram (GPL) не берём — только поведение, своими компонентами.

## Как это в Telegram (что переносим)

**Откуда пересылают**
- Меню сообщения — «Переслать» (у альбома — весь альбом).
- Режим выбора: панель снизу с «Переслать» (выбранные по порядку).
- Круглая кнопка со стрелкой рядом с пузырём: проявляется при наведении (на телефоне видна всегда), у входящих
  справа, у своих слева, внизу пузыря. В Telegram — только в каналах; у нас каналов нет, поэтому — у всех сообщений
  с медиа и у длинных постов при наведении (как просили).
- Просмотр фото — кнопка «Переслать» в шапке.

**Окно «Переслать в…»** (модалка): заголовок, поиск (в мультивыборе — чипы выбранных), полоса частых собеседников,
вкладки папок (если папок больше одной), список чатов с кружками-галочками справа.
- Ничего не выбрано — кнопка «Выберите чаты» (неактивна).
- Выбран один — «Переслать».
- Выбрано несколько — вместо кнопки поле «Добавить подпись…» и круглая кнопка отправки.
- В списке только чаты, куда можно писать (без служебного «Relay» и без тех, где нас заблокировали).
- Клавиатура: фокус в поиске, стрелки по списку, Enter — отправить выбранным.

**После выбора одного чата** — открывается этот чат, в поле ввода панель (как у ответа):
стрелка-«переслать», «От: Имя» (или «Имена отправителей скрыты»), превью сообщения или «N пересланных сообщений», крестик.
Клик по панели — меню: «Показывать отправителя / Скрыть отправителя», «Показывать подписи / Скрыть подписи»
(если есть подписи), «Другой чат…». Можно дописать комментарий — он уйдёт первым, потом пересланное.
Esc / крестик — отмена.

**Несколько чатов** — отправляется сразу во все (подпись — отдельным сообщением перед пересланным), тост
«Сообщение переслано в N чатов».

**В ленте** у пересланного сверху пузыря: стрелка + «Переслано от» + маленький аватар + имя цветом автора
(клик — открыть чат с ним). Альбомы остаются альбомами, файлы не загружаются заново. Переслали пересланное —
сохраняется исходный автор. Скрыли отправителя — заголовка нет, сообщение выглядит как своё.

## Что у нас уже есть
- Отправка с вложением, альбомы (groupId), ответы; оптимистичные сообщения в движке (outbox).
- `fileFor` уже даёт скачать файл всем участникам чата, где он лежит в сообщении — значит, пересланное медиа
  станет доступно получателям без копирования файла.
- В UI-ките: `SelectionBar` (с кнопкой «Переслать»), у `Bubble` — режим выбора и заготовка заголовка «Переслано».
- Нет: полей пересылки в сообщении, отправки чужого вложения, мультивыбора в ленте, выбора чатов.

## План

### 1. Сервер
1. Миграция 122: `messages.fwd_from jsonb` — `{userId, name, chatId, messageId, at}` (исходный автор, его имя
   на момент пересылки, откуда и когда).
2. Протокол: в `Message` — `fwdFrom?`; кадр `forward {reqId, fromChatId, ids[], toChatIds[], clientIds[],
   hideSender?, hideCaptions?, comment?}`.
3. `forwardMessages`: проверить участие в исходном чате и право писать в каждом целевом (блокировки как у send),
   взять сообщения (не удалённые, не служебные), для каждого цели — вставить копии в одной транзакции:
   то же вложение (jsonb как есть, без проверки владельца — доступ даёт исходный чат), тот же текст и форматирование
   (подпись у медиа — по флагу), новый groupId на альбом, `fwd_from` (у пересланного пересланного — исходный),
   без `reply_to`. Идемпотентность по clientId, журнал/push/поиск как у send. Комментарий — обычным сообщением первым.
4. `toMessage` и выборки последнего сообщения — с `fwdFrom`.
5. Тесты: права (чужой чат, блокировка, служебный чат), альбом, скрытый отправитель, пересылка пересланного,
   доступ к файлу у получателя, идемпотентность.

### 2. Движок
1. Действие `forward`: оптимистичные копии в каждом целевом чате (статус «отправляется»), очередь как у send,
   подтверждение по clientId.
2. `fwdFrom` в локальных сообщениях и превью списка чатов («Переслано: …»).

### 3. Интерфейс
1. **Мультивыбор в ленте**: «Выбрать» в меню сообщения, клик по пузырям отмечает, панель `SelectionBar` вместо
   поля ввода (Переслать / Копировать / Удалить), Esc — выход.
2. **Окно «Переслать в…»** (новый компонент в UI-ките, `ChatPicker`): поиск, частые, папки, список с галочками,
   кнопка/поле подписи; доступность (роли listbox/option, клавиатура).
3. **Панель пересылки в поле ввода** (как панель ответа) с меню опций и «Другой чат…».
4. **Заголовок «Переслано от»** в пузырях всех видов (текст, фото/альбом, файл, голосовое, кружок, музыка).
5. **Круглая кнопка-стрелка** у пузыря при наведении.
6. «Переслать» в меню сообщения и в просмотре фото; тост после отправки в несколько чатов.

### 4. Проверка
Сервер — тесты. В браузере: все точки входа, один чат с комментарием и опциями, несколько чатов, альбом,
пересылка пересланного, скрытый отправитель, получатель открывает файл; светлая/тёмная тема.

## Порядок работ (отдельные коммиты, в worktree `relay-forward`)
1. Сервер + протокол + тесты.
2. Движок.
3. Заголовок «Переслано от» в пузырях + меню «Переслать» + окно выбора чатов (один и несколько).
4. Панель пересылки в поле ввода с опциями.
5. Мультивыбор и круглая кнопка-стрелка; просмотр фото.
6. Проверка, слияние в master.

## Не делаем (нет у нас)
Каналы, платные чаты (звёзды), темы форумов, «Избранное» (Saved Messages) — можно добавить отдельно позже.
