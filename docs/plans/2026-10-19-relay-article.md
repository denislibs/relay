# «Статья» (Article) — расширенный редактор, как в Telegram Web A

Изучено по исходникам telegram-tt (только поведение; код GPL не берём) и в живом интерфейсе Telegram Web A.
Ключевые места у них: `components/common/Composer.tsx`, `middle/composer/MessageInput.tsx`, `RichEditorToolbar.tsx`,
`richInput/*`, `helpers/richEditor*.ts`, `ui/textInput/richText.ts`, `ui/textInput/TextFormatter.tsx`,
`iv/RichContent.tsx`, `common/MessageRichText.tsx`, `api/types/richMessage.ts`.

## Главное
- **Отдельного редактора статей нет.** Это то же поле ввода чата (у них — Tiptap 3), переключённое в режим
  «развёрнуто»: пилюля композера растёт вверх на всю высоту колонки под шапкой (шапка чата остаётся).
- Значение поля — всегда **список блоков**. При отправке пробуют перевести блоки в обычный текст + оформление
  (entities): получилось — уходит **обычное сообщение**; нет (заголовки, списки, таблицы, формулы, медиа внутри…)
  — уходит **«богатое» сообщение** (`rich_message`, блоки как в Instant View).
- Звёздочки в меню — только подсказка «это Premium»; в редакторе ничего не запрещено. Проверка — при отправке:
  без Premium окно «Убрать оформление?» (подписаться / превратить в простой текст).

## Вход, разворот, сворачивание
- Скрепка → **«Статья»** (только в обычном чате, не при правке медиа). Кнопка **«Открыть полный редактор»**
  (⤢ справа вверху поля) — появляется, когда в поле от 3 строк и нет вложений.
- **Само разворачивается**, если ввели то, что не выразить обычным текстом (например, `# ` → заголовок).
  Свёрнутое «богатое» содержимое — превью на 3 строки только для чтения; клик — развернуть.
- Свернуть: кнопка ⤡, **Esc**, клик мимо поля (кроме меню/модалок/эмодзи), отправка. Нельзя, пока грузятся медиа.
- Отправка в развёрнутом виде — **Ctrl/Cmd+Enter** (Enter — новая строка).
- Черновик: простой — как текст, «богатый» — блоками (у нас: сохраняем блоки в черновике).

## Раскладка и анимация
- Пилюля композера растёт вверх до шапки (высота = экран − шапка − отступы), лента под ней.
- Пока развёрнуто, скрыты: закреп/плеер под шапкой, кнопки «вниз», панель ответа/правки, превью ссылки, drop-зона.
- Сверху слева — **Отменить / Вернуть** (уезжают вверх и гаснут, 200 мс), справа — **Свернуть**.
- Снизу выезжает **панель инструментов** (высота 0 → высота кнопки, сдвиг снизу, 300 мс `cubic-bezier(.33,1,.68,1)`).
- Внутри поле во всю ширину пилюли, сверху/снизу — мягкое затухание при прокрутке.
- Наблюдение в живом интерфейсе: рост 48 → ~365 px за 1–2 кадра (сама высота почти не анимирована).

## Панель инструментов (слева направо)
1. **Скрепка** — в развёрнутом виде файлы вставляются **внутрь статьи** блоками медиа (фото/видео/аудио/файл,
   из 2+ фото — коллаж или слайдшоу), подпись к медиа, загрузка сразу, пока грузится — отправка заблокирована.
2. **ИИ** — редактор с ИИ (у нас — позже/по желанию).
3. **«+» Вставить блок**: Заголовок (уровни 1–6) · Подвал (мелкий серый) · Цитата (с подписью-автором,
   сворачиваемая) · Выноска (pullquote: по центру, курсив, кавычки) · Спойлер-раздел (details: заголовок + тело) ·
   Разделитель · Ряд кнопок (до 8: ссылка / профиль / копировать текст; стиль обычный/основной/опасный/успех).
4. **Списки**: маркированный · нумерованный · чек-лист; «Настройки списка»: тип, галочки, нумерация 1/a/A/i/I,
   обратный порядок; вложенные списки.
5. **Таблица**: сразу 2×2 + поле «Заголовок»; выделение ячеек/строк/столбцов, ручка-меню: выравнивание, шапка,
   полосатая/компактная/без рамок, объединить/разделить, вставить/переместить/удалить строки и столбцы,
   перетаскивание строк и столбцов.
6. **Ссылка** — окно «Создать ссылку» (текст + адрес).
7. **Блок кода** — с выбором языка и подсветкой.
8. **Формула** — LaTeX (блок или в строке), исходник в плавающем поле над формулой.
9. **Эмодзи**, 10. **Отправить**.

## Оформление в строке (всплывает над выделением)
Цитата · Спойлер | Жирный · Курсив · Подчёркнутый · Зачёркнутый · Моноширинный | Дата · Ссылка |
(в развёрнутом) Кнопка-в-строке · Маркер · Нижний индекс · Верхний индекс | Очистить.
Горячие клавиши: Mod-b/i/u, Mod-m (код), Mod-k (ссылка), Mod-s (зачёркнутый), Mod-p (спойлер), Mod-n (очистить),
Mod-Shift-b (цитата), Mod-z / Mod-Shift-z. Быстрый ввод: `# `…`###### `, `> `, ` ``` `, `---`, `- `, `1. `,
`$…$`, `$$…$$`, `||спойлер||`, `==маркер==`, `[текст](url)`, `--`→—, `<<`/`>>`→«».

## Вставка, перетаскивание, отмена
- Вставка HTML → в блоки; простой текст, похожий на markdown, → разбирается как markdown; иначе — абзацы по строкам.
- Файлы: в развёрнутом — внутрь статьи, в свёрнутом — обычное окно отправки.
- Перетаскивание файлов — только в развёрнутом; место — между блоками, с линией-индикатором.
- Отмена/возврат — история редактора; программные изменения (черновик, подписи) в историю не попадают.

## Лимиты
Длина 32 768 (UTF-8), блоков 500, вложенность 16, медиа 50, столбцов таблицы 20.

## Как выглядит в ленте
Богатое сообщение рисуется блоками: заголовки (H1 крупный, H2 по центру), подвал серым, код с языком и
«копировать», разделитель, списки (в т.ч. галочки), цитата с автором, выноска, раскрывающийся раздел, таблица с
горизонтальной прокруткой, формула, ряд кнопок, медиа во всю ширину (коллаж/слайдшоу) с подписью. Длинное —
свёрнуто с затуханием и «Показать полностью».

## Что есть у нас
- Своё поле ввода (contenteditable + entities: жирный, курсив, подчёркнутый, зачёркнутый, спойлер, код, ссылка,
  цитата), всплывающая панель форматирования, markdown-сокращения, сообщения = текст + entities.
- Нет: режима «развёрнуто», блоков, «богатых» сообщений и их отрисовки.

## План для Relay (по этапам, каждый — рабочий результат)

**Решение по движку редактора.** Tiptap/ProseMirror — MIT (лицензия подходит, код Telegram не берём), это
сэкономит месяцы на таблицах, списках, истории и вставке. Альтернатива — растить своё поле (дольше, рискованнее).
Предлагаю Tiptap только для **развёрнутого** режима (обычное поле остаётся нашим, лёгким), с переводом
наших entities ⇄ документ при развороте/сворачивании.

1. **Модель и сервер.** Сообщение получает `blocks` (jsonb, свои типы: paragraph, heading1–3, list/orderedList/
   checklist, quote(+caption), pullquote, details, divider, code(lang), table, math, media, buttons), проверка
   лимитов и допустимых типов на сервере; `body` = простой текст (превью в списке чатов, поиск, уведомления).
   Если блоки сводятся к тексту+entities — отправляем обычным сообщением (как у Telegram).
2. **Отрисовка в ленте** (UI-кит `RichBlocks`): все типы блоков, длинное — свёрнуто с «Показать полностью».
3. **Развёрнутый редактор**: разворот/сворачивание (кнопка, «Статья» в скрепке, Esc, авто-разворот), анимации,
   Отменить/Вернуть, панель инструментов, «+», списки, ссылка, код, Ctrl/Cmd+Enter, черновик блоками.
4. **Таблицы** (вставка, выделение, меню действий) и **формулы** (KaTeX/temml — MIT).
5. **Медиа внутри статьи** (загрузка сразу, коллаж/слайдшоу, подписи) и **ряд кнопок**.
6. Вставка HTML/markdown, перетаскивание, проверка, слияние.

Без «Премиума» у нас ограничений нет — звёздочки не рисуем.
Порядок можно сократить до MVP: 1 → 2 → 3 (без таблиц/формул/медиа) — уже даст статьи с заголовками, списками,
цитатами, кодом и разделителями.
