# Цветовые темы как в Telegram Web — план

Цель: экран «Тема» как в tweb и всё, что за ним стоит: четыре базовые темы + «Системная», тёмная тема,
окрашенная акцентом, наборы акцентов у каждой темы, готовые темы плитками, тема отдельного чата, повышенная
контрастность, обои у каждой темы. Поведение и формулы — по tweb (`~/Documents/tweb`, GPL: только поведение,
числа и имена; код не переносим) и iOS-клиенту Telegram (коэффициенты — как данные). Картинки и эмодзи-анимации
Telegram не используем: эмодзи — системные, узоры обоев — свои.

## Что выяснилось про tweb (и что это меняет)

- **Градиентных пузырей в tweb нет.** `message_colors` (1–4 цвета) усредняются в один сплошной цвет
  (поканально `(a+b)/2`, затем «пересадка» на базовый цвет темы по HSV). Делаем так же — сплошной пузырь.
- **Тему чата tweb только показывает** (берёт эмодзи темы из профиля собеседника / канала, красит контейнер
  чата переменными, ставит обои темы). Поставить её нельзя. У нас своего сервера Telegram нет — ставить тему
  будем сами (как мобильные клиенты Telegram): чат, служебное «X изменил(а) тему чата на 🐥».
- **Контрастность в tweb скрыта** за `?a11y=1`. У нас — обычный переключатель в настройках.
- **«Системная» в tweb жёстко** «Classic днём / Night ночью». У нас — последняя выбранная светлая и тёмная
  (у tweb это `lastThemeNames`, используется для переключателя в меню).

## Базовые темы

| Пункт | id | `data-theme` | Основа | Свои пузыри | Обои по умолчанию |
|---|---|---|---|---|---|
| Классическая | `classic` | light | нынешняя светлая | бледный тон акцента, тёмный текст | узор, 4 цвета |
| День | `day` | light | светлая, поверхности белые/серые | **залиты акцентом, белый текст** | без узора, светлый градиент |
| Ночь | `night` | dark | нынешняя тёмная (нейтральная) | приглушённый акцент | узор-маска |
| Тёмная | `tinted` | dark | **всё из акцента** (формулы iOS) | из акцента | тёмный градиент цвета акцента |
| Системная | `system` | по ОС | последняя светлая / последняя тёмная | | |

`data-theme` остаётся `light|dark` — на нём 34 правила CSS, кит обоев и анимация смены темы. База — в новом
атрибуте `data-base` (для редких различий в CSS, напр. текст в пузырях «Дня»).

### «Тёмная» из акцента (iOS `DefaultDarkTintedPresentationTheme`)
Акцент → HSV, яркость не ниже 0.18; каждая поверхность — акцент с множителями (оттенок, насыщенность, яркость):
фон `1.024, 0.585, 0.25`; второй фон `1.024, 0.573, 0.18`; поле ввода `1.02, 0.609, 0.15`;
разделитель `1.033, 0.426, 0.34`; вторичный цвет `1.019, 0.109, 0.59`; вторичный текст `0.956, 0.17, 1.0`.
Свой пузырь, если у набора нет цвета пузыря: `низ = акцент × (1.019, 0.731, 0.59)`, `верх = низ × (0.966, 0.61, 0.98)`,
усреднение → сплошной. Наши токены раскладываются на эти роли (таблица — в коде `themes.ts`).

### Наборы акцентов у каждой базы
Набор = акцент + (необязательно) цвет пузыря + (необязательно) обои. Числа — из iOS-пресетов (данные):
- Классическая — 7 наборов с обоями; День — 4 набора без обоев; Ночь — 3 набора с тёмными обоями;
- Тёмная — 9 базовых цветов (blue, cyan, green, pink, orange, purple, red, yellow, gray), у каждого свой тёмный
  градиент обоев (`TINTED_BASE_WALLPAPERS`).
Первый кружок — «как в теме» (без набора). Кружок с двумя цветами пузыря рисуется диагональным градиентом.
Наш зелёный акцент остаётся акцентом «как в теме» у Классической и Ночи.

## Расчёт цветов (как `applyAppColor`)

`computePalette(base, choice, {contrast})` → `{ '--token': value }` поверх `tokens.css`:
1. База: токены светлой/тёмной темы из `tokens.json` + поправки базы («День», «Тёмная»).
2. Акцент: нынешний сдвиг фирменных токенов (`accent.ts`) — для Классической/Ночи/Дня; для «Тёмной» —
   поверхности целиком из акцента.
3. Пузырь: цвет набора (усреднённый) или правило базы; `--out-ink`, `--out-meta`, ссылки и галочки в пузыре —
   из контраста с пузырём.
4. Обои: цвета набора или базы → `--wallpaper-1..4`, `--wallpaper-pattern`.
5. Контрастность (вкл.): `ensureTextContrast(color, bg, 4.9)` — WCAG-яркость, сдвиг к чёрному/белому
   бисекцией (20 шагов), для `ink-muted`, `brand-text`, `danger`, ссылок, `out-meta`, `on-button`;
   `html.rl-contrast` — подчёркнутые ссылки, плейсхолдеры цветом вторичного текста.

Применение: `<style id="rl-theme">` с готовым CSS (заменяет `rl-accent`) + `relay.themeCss` в localStorage для
`boot.js` (без вспышки при загрузке), `meta[name=theme-color]` — цвет панели. Смена — существующая анимация:
круг при смене светлая↔тёмная, плавное смешивание палитр внутри одной стороны (теперь и Ночь↔Тёмная).

## Настройки (prefs v2)
```
theme: 'system' | 'classic' | 'day' | 'night' | 'tinted'
lastLight: 'classic' | 'day'      lastDark: 'night' | 'tinted'
themes: { [base]: { preset: string | null, custom?: { theme: themeId } , wallpaper: WallpaperPref } }
contrast: boolean
```
Миграция v1 → v2: `light→classic`, `dark→night`; `accent` → набор «как в теме» с этим акцентом у Классической
и Ночи; `wallpaper.light → classic`, `wallpaper.dark → night`; День и Тёмная — обои по умолчанию.
Экран «Обои» правит обои **текущей** базы.

## Готовые темы (плитки)
Каталог на сервере: `GET /themes` → `[{ id, emoji, title, settings: { classic, day, night, tinted } }]`, где
каждая запись — `{ accent, bubble?, wallpaper?: { colors[4], pattern, intensity } }`. Каталог — статичные
данные в сервере (наши цвета и узоры), клиент кэширует. Первая плитка — 🏠 «по умолчанию».
Плитка 72×96: мини-обои (CSS-градиент + узор, как `Swatch` в `Wallpaper.tsx`, без canvas), два пузыря-«пилюли»
цветами темы (переменные на самой плитке), эмодзи. Выбранная — кольцо акцента. Выбор плитки задаёт текущей базе
`{ theme: id }`; сброс — 🏠.

## Тема чата
- Сервер: `chats.theme text null` (id из каталога), `PUT /chats/:id/theme { theme: id | null }`. Личный чат —
  любой участник; группа/канал — админ с правом менять информацию. Служебное сообщение `theme_changed`
  `{ emoji | null }`, событие `chatTheme { chatId, theme }` через `chatEvent` (в личном — в журналы обоих).
  `ChatSummary.theme`, `GroupInfo` не трогаем.
- Клиент: движок хранит `LocalChat.theme` (в подписи строки), операция с откатом; пункт меню чата «Тема чата» →
  лист с плитками; открытый чат красится переменными темы на своей колонке (акцент, пузыри), обои за ним — обои
  темы для текущей стороны (светлая/тёмная берётся глобальная, как в tweb). Служебное сообщение и превью в
  списке («Тема чата: 🐥»).

## Этапы (каждый — отдельный коммит, тесты, проверка в Chrome)
1. **Ядро расчёта** — `apps/web/src/themes/` (`palette.ts`, `presets.ts`, `contrast.ts`, `color.ts`), тесты
   (`bun test` в `apps/web`): формулы «Тёмной», усреднение пузыря, контраст, наборы.
2. **prefs v2 + применение** — миграция, `data-base`, `rl-theme` + `boot.js`, `theme-color`, смешивание
   палитр между любыми базами, обои по умолчанию у каждой базы.
3. **Экран темы** — радиокнопки (5), ряд наборов для текущей базы, контрастность, обои по базе, поиск настроек.
4. **Готовые темы** — каталог и `GET /themes` на сервере, плитки, выбор/сброс.
5. **Тема чата** — миграция, маршрут, служебное сообщение, журнал, движок, меню чата, окраска колонки и обоев.
6. **Проверка целиком** — Chrome: все базы × наборы, плитки, тема чата у обоих собеседников, контрастность,
   загрузка без вспышки; тесты сервера, движка и `apps/web`.
