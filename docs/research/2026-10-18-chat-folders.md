# Папки с чатами: исследование и решения

Источники — поведение Telegram Web A (telegram-tt, `~/Documents/telegram-dd/reference/telegram-tt`) и Web K (tweb, `~/Documents/tweb`). Код обоих под GPL — берём только поведение, реализация своя.

## Что делают оба клиента

**Модель папки.** id, название (до 12 символов), эмодзи-иконка, включённые чаты, исключённые чаты, закреплённые в папке, флаги типов (контакты, не контакты, группы, каналы, боты) и флаги исключения (без звука, прочитанные, архив). «Все чаты» — встроенная папка id 0, не хранится. Лимиты: 10 папок, 100–200 чатов в папке.

**Попадание чата в папку** — строго по порядку:
1. в исключённых → нет;
2. во включённых (или закреплённых) → да;
3. исключать прочитанные и непрочитанного нет → нет;
4. исключать без звука и чат заглушён (кроме упоминаний) → нет;
5. флаги типов: личный с контактом → «контакты», с не-контактом → «не контакты», группа → «группы»; иначе нет.

Явное исключение сильнее всего, явное включение сильнее флагов исключения. При сохранении чат, попавший в оба списка, убирается из исключённых.

**Порядок в папке** — закреплённые в папке, затем по последней активности (как основной список).

**Счётчик на вкладке** — число непрочитанных *чатов*, не сообщений. Серый, если все непрочитанные заглушены; скрыт при нуле.

**Вкладки сверху.** Полоса показывается только если есть хотя бы одна своя папка (иначе — сразу список). Активная вкладка — «таблетка» (tt: второй слой подписей с clip-path, tweb: заливка, 200 мс). Много вкладок — горизонтальная прокрутка, активная держится в видимой области. Смена папки — горизонтальный слайд списка по направлению индекса. Клик по активной — список в начало. Esc / Назад — к «Все». tt: Ctrl+Shift+1…9.

**Вкладки слева.** Отдельная колонка 72–80 px: сверху кнопка меню, ниже папки (иконка ~30 px, бейдж на иконке, подпись 10–11 px в одну строку), внизу кнопка настроек папок. Активная — подложка-таблетка, переезд 300 мс. Иконка: эмодзи из названия/поля эмодзи → иконка; один флаг типа → его иконка; иначе папка. На узком экране (≤ 925 px) колонка прячется, работают вкладки сверху. Переключатель «слева / сверху» — в настройках папок и в контекстном меню вкладки. Это настройка устройства.

**Контекстное меню вкладки.** «Все»: изменить папки, прочитать все. Своя: изменить, прочитать все, удалить (красным). В конце — «Вкладки слева / сверху».

**Настройки → Папки с чатами.** Картинка, пояснение, «Создать папку». Список папок: подпись «N чатов» или название единственного флага, перетаскивание за ручку (порядок уходит на сервер), меню ⋯ → Удалить. «Рекомендуемые» с кнопкой «Добавить» (исчезает после добавления). «Вид вкладок»: слева / сверху.

**Редактор папки.** Название (≤ 12) и иконка. «Включённые чаты»: «+ Добавить чаты», чипы типов, первые 4–5 чатов + «Показать ещё N». «Исключённые»: то же с чипами «Без звука», «Прочитанные». Выбор чатов — отдельный экран: чекбоксы типов сверху, поиск, список чатов с галочками. Сохранение — галочка (FAB), появляется после правок. Проверки: пустое название; ни одного чата и ни одного типа. Уход с несохранёнными правками — подтверждение. Удаление — диалог подтверждения.

**«Добавить в папку»** в меню чата: только если есть свои папки; список папок с галочками, снятие галочки убирает чат из включённых (tweb ещё добавляет в исключённые, если чат попадал по типу).

**Пустая папка.** Иконка 📂, «В этой папке пока нет чатов», кнопка «Изменить папку».

**Синхронизация.** Папка уходит на сервер целиком (upsert), удаление и порядок — отдельно; другие устройства получают событие. tt не оптимистичен, tweb — оптимистичен для закреплений.

**Подгрузка.** У своих папок нет серверной выдачи: клиент листает общий список диалогов и фильтрует. Папка «догружена», когда догружен общий список.

## Как это ложится на Relay

| Telegram | Relay |
|---|---|
| каналы, боты, архив | нет — флагов нет |
| закреплённые в папке | закреплений в Relay нет вообще — позже, отдельной задачей |
| «без звука» | заглушение пока только на устройстве (`relay.muted`), поэтому и фильтр работает по нему |
| «контакт» | книга контактов движка (`contacts`), по `peerId` личного чата |
| теги папок на строках (premium) | не делаем |
| ссылки-приглашения на папку | не делаем |
| цвет папки | не делаем |

## Решения

1. **Хранение — часть настроек аккаунта.** `user_settings.folders jsonb` (упорядоченный массив). Правки — `PUT /settings/folders/:id`, `DELETE /settings/folders/:id`, `PUT /settings/folders/order`; каждая — одной транзакцией с `settingsChanged` в журнал владельца и ответом-снимком. Так папки сразу получают всё, что уже есть у настроек: кэш в IndexedDB, порядок по seq журнала, офлайн-очередь операций, оптимистичный вид (база + очередь), повторную загрузку после hello. Правка по одной папке (а не весь список) — чтобы правки разных папок с двух устройств не затирали друг друга.
2. **Фильтр — чистая функция в вебе** (`folders.ts`) по данным, которые уже есть в клиенте: чат (`kind`, `peerId`, `unread`), контакты, заглушённые. Покрыта тестами.
3. **«Все»** — всегда первая, не хранится, не перемещается.
4. **«Непрочитанные»** перестаёт быть зашитой вкладкой: становится рекомендуемой папкой (флаги «контакты, не контакты, группы» + «исключить прочитанные»). Рекомендуемые: «Непрочитанные», «Личные» (контакты + не контакты), «Группы».
5. **Лимиты:** 10 папок, 200 чатов в каждом списке, название ≤ 16 символов (по графемам). У Telegram 12, но по-русски не влезает даже «Непрочитанные» (13).
6. **Положение вкладок** — настройка устройства в `prefs` (`folders.position: 'top' | 'left'`), по умолчанию сверху.
7. **Подгрузка своих папок** — как в tweb: у края списка папки догружаем общий список диалогов.
8. **Плавность:** вкладки и колонка появляются/исчезают без рывков списка; смена папки — существующий слайд `SlideStack`; таблетка — существующая механика `FolderTabs`.

## Объём первой версии

Сервер (хранение, проверки, журнал) → движок (папки в настройках, действия, оптимистичный вид) → веб: фильтр и счётчики, вкладки сверху из папок, колонка слева, контекстное меню вкладки, страница «Папки с чатами», редактор с выбором чатов, пустая папка, «Добавить в папку» из меню чата, Ctrl+Shift+1…9 и Esc.
