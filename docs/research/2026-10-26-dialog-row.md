## Вторая строка

### Порядок частей

1. Префикс «Вы: » / «Имя: » или вместо него красное «Черновик: ».
2. Серая иконка-маркер: переслано (↪) или ответ на историю.
3. Одна миниатюра 20×20.
4. Иконка типа, метки через «, », затем текст.

Вся строка — одна inline-линия с одним многоточием в конце. Переносы строк превращаются в пробелы через `white-space: nowrap`.

### Текст

- **Цвет и размер:** серый (`secondary`), 14/20.
- **Оформление снимается:** жирный, курсив, моноширинный, цитаты и ссылки становятся обычным текстом. Упоминания и ссылки не кликаются.
- **Зачёркнутый остаётся зачёркнутым.** Это единственное исключение.
- **Кастомные эмодзи** рисуются как есть. Одноцветные красятся в серый, а в выбранной строке в белый.
- **Спойлер:** буквы заменяются случайными символами, поверх анимированные точки цвета текста. Настоящий текст в DOM не попадает.
- **Длина:** после trim, если длиннее 110 символов, остаются первые 100 и «...». Дальше текст режет CSS.
- **Код входа** от служебного аккаунта прячется под спойлер.

### Префикс отправителя

- **Где есть:** только в группах и каналах, если отправитель не сам чат и сообщение не сервисное.
- **Своё сообщение:** «Вы: ».
- **Чужое:** имя без фамилии и «: ». От имени канала — название канала.
- **Цвет:** основной цвет текста (чёрный), не акцент. В выбранной строке белый.
- **Где нет:**
  - в личке, в том числе для своих сообщений: там своё видно по галочкам;
  - в «Избранном»;
  - в постах канала;
  - у анонимного админа.

### Миниатюра

- **Для каких сообщений:**
  - фото, видео, GIF, кружок;
  - фото или видео из превью ссылки;
  - платное медиа и invoice;
  - новое фото группы в сервисном сообщении.
- **Каких нет:** стикер, файл, музыка, голосовое, контакт, гео, игра, история. Самоуничтожающееся медиа тоже без миниатюры.
- **Вид:**
  - 20×20, скругление 4, отступ справа 6, `object-fit: cover`;
  - кружок рисуется кругом;
  - на видео, GIF и кружке белый `play` 16 px по центру, на кружке 14 px.
- **Спойлер на медиа:** миниатюра размыта, с частицами.
- **Альбом:** всегда одна миниатюра, медиа верхнего сообщения.
- **Если есть миниатюра:** иконка типа не ставится. Если есть подпись, слово типа тоже не пишется: миниатюра + подпись.

### Типы сообщений

Метки и иконки серые, акцентного цвета нет. Иконки в tweb — inline-иконки шрифта, не эмодзи.

| Сообщение | Что видно |
|---|---|
| Текст | текст по правилам выше |
| Фото | ▣ «Фото», с подписью ▣ подпись. Без миниатюры: «Фото» или «Фото, подпись» |
| Альбом | ▣ «Альбом» или ▣ «Альбом, подпись». Подпись — общая подпись группы; если она в верхнем сообщении, просто ▣ подпись |
| Видео | ▣▶ «Видео» / подпись |
| Кружок | ●▶ «Видеосообщение» |
| GIF | ▣▶ «GIF» |
| Голосовое | «Голосовое сообщение», без иконки и длительности |
| Стикер | «😀 Стикер», без миниатюры, подпись игнорируется |
| Один эмодзи | как текст |
| Музыка | 🎵-иконка «Название - Исполнитель», без тегов — имя файла; «, подпись» |
| Файл | 📄-иконка «имя.pdf», «, подпись» |
| Контакт | 👤-иконка «Контакт», имя не пишется |
| Гео / трансляция гео / место | 📍-иконка «Геопозиция» / «Трансляция геопозиции» / «Геопозиция, Название места» |
| Опрос, викторина | 📊-иконка + вопрос, викторина не отличается |
| Кубик | только эмодзи 🎲 / 🎯 … |
| Игра | «🎮 Название» |
| Invoice | 💳-иконка + название |
| История | иконка истории + «История»; упоминание: «X упомянул(а) вас в истории» |
| Ответ на историю | серая иконка перед текстом |
| Чек-лист | ☑-иконка + заголовок |
| Платное медиа | ⭐ «Фото» / «N фото» / «N медиа» + миниатюра |
| Превью ссылки | просто текст со ссылкой + миниатюра превью, метки нет |
| Самоуничтожающееся | «X отправил(а) исчезающее фото…» / «Фото истекло» |
| Неподдерживаемое | «Сообщение не поддерживается…» |
| Ответ на сообщение, via @bot | никак не отмечаются |

### Пересланное

- **Как выглядит:** серая иконка ↪ (20×20, `#a2abb2`) перед миниатюрой и текстом.
- **Слова «Переслано» и имени автора оригинала нет.** В префиксе стоит тот, кто переслал.
- **Пост канала в группе обсуждения:** «Канал: » + ↪.
- **Иконки нет:** в черновике и в подчатах «Избранного».

### Сервисные сообщения

- **Общее:** без префикса, имена внутри текста, серым, без ссылок.
- **Иконки:** спереди только у звонков (трубка) и подарков или розыгрышей (подарок).
- **Своё действие:** отдельные формулировки: «Вы создали группу», «Вы вступили в группу».
- **Закреп:** «X закрепил(а) «превью закреплённого»». Превью закреплённого строится теми же правилами. Если закреплённого сообщения нет: «X закрепил(а) сообщение».
- **Звонки:** «Входящий звонок (1:23)», «Пропущенный звонок», то же для видеозвонков.
- **Смена фото:** миниатюра нового фото.

### Черновик

- **Метка:** «Черновик: » красным, в выбранной строке белым.
- **Вытесняет последнее сообщение целиком:** нет префикса, миниатюры, иконок, ↪ и галочек.
- **Время:** берётся максимум из времени черновика и времени последнего сообщения.

### «Печатает» и другие действия

- **Переход:** вторая строка кроссфейдом сменяется индикатором. Пока индикатор виден, новые сообщения и черновики строку **не перерисовывают**. После него превью возвращается кроссфейдом.
- **Тексты:**
  - в личке: «печатает», «отправляет фото / видео / файл», «записывает голосовое / видео», «выбирает стикер», «играет в игру», «смотрит 😀»;
  - в группе: «Имя печатает», «A и B печатают», «A и ещё N печатают»;
  - если действия у нескольких людей разные, все сводятся к «печатают».
- **Анимации:**
  - текст — три пульсирующие точки;
  - загрузка — бегущая полоска 13×5;
  - запись — мигающая точка;
  - стикер или эмодзи — «глаза».
- **Цвет:** серый, не акцент; в выбранной строке белый. У ботов индикатора нет.

## Первая строка и бейджи

### Время

Правила по порядку:

1. Сегодня — ЧЧ:ММ.
2. Другой год — дд.мм.гггг.
3. Эта неделя — короткий день недели.
4. Иначе — «12 мар».

Цвет серый.

### Галочки

- **Когда видны:** только у своих последних сообщений, не в «Избранном» и не при черновике.
- **Цвет:** акцентный.
- **Состояния:** часы с крутящимися стрелками при отправке → одна галочка → две; ошибка — красный кружок «!». Переходы между значками морфятся.

### После названия

- **Значки по порядку:** SCAM/FAKE, эмодзи-статус или звезда premium, verified.
- **Без звука:** серый динамик 🔇 18 px, `#a2abb2`, появляется с fade. В выбранной строке белый с прозрачностью 70%.

### Бейджи справа

Порядок: ❤ → @ → счётчик → 📌.

- **Размер:** 22 px, жирный 14 px.
- **Счётчик:**
  - формат 999 / 1K / 2.3K / 1.5M;
  - отметка «непрочитано» без числа — пустая пилюля;
  - цвет акцентный, у заглушённого чата серый;
  - смена числа прокручивается по цифрам.
- **@:**
  - если всё непрочитанное — одно упоминание, сам счётчик становится «@»;
  - иначе отдельный кружок «@»;
  - всегда акцентный, даже в заглушённом чате.
- **❤:** красный кружок с белым сердцем, если есть непросмотренные реакции.
- **📌:** без фона, `#a2abb2`. Если есть другие бейджи, булавка уходит под них, и счётчик её перекрывает.

### Аватар и строка

- **Онлайн:** точка 14 px с рамкой цвета фона, акцентная (не зелёная), переход 250 мс.
- **Выбранная строка:** акцентный фон, всё белое, бейджи инвертированы.
- **Архив:** градиентный аватар; под названием до 10 имён через «, », непрочитанные жирнее; серый счётчик.

## Relay против tweb

Смотрел `packages/relay-ui/src/kit.js` (`ChatRow`), `apps/web/src/ui/preview.tsx`, `apps/web/src/ui/Sidebar.tsx` (`SideRow`) на master `f9e340b`.

### Уже как в tweb

- **Порядок второй строки:** печатает → черновик → «Автор: » + миниатюра 20 px + текст.
- **Префикс:** только в группах, «Вы» / первое имя, цвет основного текста.
- **Миниатюры:** фото, видео с play, кружок, обложка музыки. Если есть миниатюра и подпись — только подпись.
- **Спойлер и переносы:** спойлер скрыт, переносы стали пробелами.
- **Стикер:** «😀 Стикер».
- **Сервисные сообщения:** без префикса.
- **Черновик:** красным, вытесняет сообщение.
- **Строка без сообщения:** «Сообщение не поддерживается» вместо пустой строки.
