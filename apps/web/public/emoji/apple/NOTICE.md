# Apple emoji images

These PNG files (64×64, one per emoji, file name = lowercase code points joined by `-`, without `fe0f`)
were copied from the public folder of Telegram Web K (`public/assets/img/emoji`), which in turn took
them from iamcal/emoji-data (`img-apple-64`): https://github.com/iamcal/emoji-data

The images are Copyright © Apple Inc. They are **not** covered by the license of this repository and
are not licensed by Apple; emoji-data states that the Apple images are not licensed for commercial use.
They are kept in this separate folder so they can be removed or replaced (e.g. with Noto Emoji or
Fluent Emoji) without touching the rest of the code.
