# Звуки звонков

Relay берёт звуки звонка отсюда (`calls/sounds.ts`). Если файла нет, играет свой синтезированный тон.

| Файл | Когда звучит |
|---|---|
| `incoming.mp3` | входящий звонок, мелодия «Стандартная» (по кругу) |
| `outgoing.mp3` | гудки у звонящего, пока у собеседника звонит (по кругу) |
| `connect.mp3` | соединились |
| `end.mp3` | звонок завершён |
| `busy.mp3` | абонент занят |
| `connecting.mp3` | переподключение (по кругу) |
| `failed.mp3` | не удалось соединиться |
| `group_join.mp3` | в групповой звонок вошёл участник (звонки до 10 человек) |
| `group_leave.mp3` | участник вышел из группового звонка |

Кладя сюда чужие звуки, проверьте их лицензию и укажите источник в этом файле.
